# Microsoft Store Screenshots

Place the following screenshots here (1920x1080 PNG recommended):

1. `dashboard.png` — Library Dashboard overview
2. `attendance.png` — Attendance tracking view
3. `students.png` — Student management page
4. `payments.png` — Payment management
5. `analytics.png` — Analytics and reports
6. `settings.png` — Library settings

## How to capture

1. Open the app in a 1920x1080 browser window
2. Navigate to each section
3. Use DevTools > More tools > Capture full-size screenshot
4. Save as PNG with the filenames above

## Requirements
- Minimum: 1366x768
- Recommended: 1920x1080
- Format: PNG
- No browser chrome visible
- Show real or realistic sample data
