## Long Description (Store listing)

Libriofy is a complete library automation platform designed for modern libraries, study centers, and co-working reading spaces. Built to help library owners streamline daily operations and grow their business.

**Key Features:**

• **Smart Dashboard** — Real-time overview of seats, revenue, student activity, and operational health at a glance.

• **QR-Based Attendance** — Fast check-in and check-out using QR codes. Works on dedicated kiosk devices or any browser.

• **Student Management** — Complete student profiles with plan details, payment history, seat assignments, and renewal tracking.

• **Payment Tracking** — Record payments, track dues, manage subscriptions, and automate renewal reminders.

• **Seat Map** — Visual seat occupancy view. Assign, reserve, and manage seats effortlessly.

• **Analytics & Reports** — Revenue trends, attendance patterns, occupancy rates, and student retention metrics.

• **Subscription Plans** — Create flexible plans (monthly, quarterly, yearly). Auto-calculate renewals.

• **Offline Support** — Key features work without internet. Data syncs automatically when connection returns.

• **Multi-device** — Works on desktop, tablet, and mobile. Install as a standalone app from any modern browser.

• **Waiting List** — Manage overflow demand with an automated waiting list.

• **Notifications** — Renewal reminders, payment alerts, and attendance notifications.

**Built for:**
- Library owners
- Study center managers
- Co-working space operators
- Reading room administrators

**Technical Highlights:**
- Works offline with automatic data sync
- Installs as a native-like app on Windows 10/11
- Responsive design for desktop and tablet
- Fast QR scanning with hardware acceleration
- Secure authentication with OTP
- Real-time data updates
